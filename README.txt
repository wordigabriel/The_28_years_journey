# Gabriel 28th Birthday Story Website

## Folder structure

- `index.html` — main webpage
- `css/style.css` — all design and animation styles
- `js/script.js` — scroll reveals, particles and parallax
- `images/` — all photos and flyers used by the page

## To test on your computer
Open `index.html` in a browser.

## To host
Upload the entire `Gabriel_28th_Birthday_Story_Website_Complete` folder to a static host such as Netlify, GitHub Pages, or Cloudflare Pages.

Do not upload only `index.html`; keep the `css`, `js`, and `images` folders beside it.
